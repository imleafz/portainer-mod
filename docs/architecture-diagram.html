Portainer Architecture

Container Management Platform for Docker, Swarm, Kubernetes and ACI

Frontend Stack

  • • React 17 with TypeScript
  • • React Query for state management
  • • Axios for HTTP requests
  • • i18next for internationalization
  • • AngularJS 1.8 (legacy views)
  • • TailwindCSS + PostCSS
  • • Webpack build system

Backend Architecture

  • • Go 1.25+ HTTP server
  • • Layered architecture: Handler → Proxy → Service → DataStore
  • • Multiple auth methods: JWT, API Key, OAuth, LDAP
  • • Docker & Kubernetes API proxying
  • • Reverse tunnel for edge devices
  • • CSRF protection & rate limiting
  • • Activity logging & audit trail

Supported Platforms

  • • Docker Standalone
  • • Docker Swarm
  • • Kubernetes
  • • Azure Container Instances
  • • Edge Computing Devices
  • • Nomad (via external proxy)
  • • Multiple registries (Docker, GitHub, GitLab, Azure)
